Install the Capture Roster bookmark

Do this once in Safari on the iPad (not inside the home-screen app). Redo it only if you change your username settings or the app tells you the bookmark has been updated.

  1. Tap Copy bookmark code below.
  2. Tap the Share button → Add Bookmark. Name it Capture Roster, save it in Favourites.
  3. Open Bookmarks (book icon) → Edit → tap Capture Roster.
  4. Clear the address field, paste, and tap Done.

Show code

Using it

  • On a login page: tap it to fill in your username if Safari hasn't. Passwords come from Safari's Passwords.
  • On the roster page: tap it, then Copy, then open Roster Manager → Capture → Import from clipboard.
